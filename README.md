# Score Now

Score Now is a simple and intuitive web application designed to help you keep track of scores for various games. Whether you're playing board games, card games, or any other competitive activity, Score Now makes it easy to manage player scores, view game history, and check the leaderboard.

## Features

- **Add Players**: Easily add players to your game with a simple interface.
- **Update Scores**: Quickly update player scores with just a few clicks.
- **Game History**: View a detailed history of score changes for each game session.
- **Leaderboard**: See the current standings of all players in real-time.
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.
- **Offline Support**: Continue using the app even without an internet connection, thanks to service workers.
- **Progressive Web App (PWA)**: Install Score Now on your device for quick access and a native app-like experience.

## Installation

1. Visit the application: https://kroljs.com/score-now/
1. (Optional) To install as a PWA, follow your browser's instructions for adding to home screen.

## Usage

1. Open the Score Now application in your web browser.
1. Add players by clicking the "Add Player" button and entering their names.
1. Update scores by dragging the player's pip around the scoring disk and release to submit the score change.
1. Update player names or remove players by long clicking on their names/scores.
1. Easily open and close the game history and leaderboard views.
1. To reset the game, click the "Reset Game" button and confirm your choice.
